Create `src/cli/stage_helpers.py` with three functions that extract the shared stage command pattern:

1. `resolve_client(client_arg: Optional[str]) -> tuple[str, Path]`:
   - If client_arg is provided, use it. Otherwise call `get_active_client()`.
   - If neither yields a name, print `[red]No client specified and no active client set. Use 'sem accounts switch <name>' or pass a client name.[/red]` and `raise typer.Exit(1)`.
   - Call `get_account(name)` to verify it exists (catch FileNotFoundError, print error, exit 1).
   - Return `(name, CLIENTS_DIR / name)`.

2. `require_prerequisites(client_dir: Path, stage: str) -> None`:
   - Call `check_prerequisites(client_dir, stage)`.
   - If not ok, print `[red]Cannot run '{stage}': prerequisite stages not completed: {', '.join(missing)}[/red]` and `raise typer.Exit(1)`.
   - Per PIPE-03: enforces stage prerequisites.

3. `complete_stage(client_dir: Path, stage: str, console: Console, duration_seconds: float | None = None) -> None`:
   - Call `update_state(client_dir, stage, "completed", metadata={"duration_s": duration_seconds} if duration_seconds else None)`.
   - Print `[green]Stage '{stage}' completed.[/green]`.
   - Per PIPE-04: updates workflow_state.json.

4. `mark_stage_started(client_dir: Path, stage: str) -> None`:
   - Call `update_state(client_dir, stage, "in_progress")`.

Imports: typer, rich.console.Console, from src.accounts.manager import get_account, get_active_client, from src.accounts.state import check_prerequisites, update_state, from src.utils.config import CLIENTS_DIR.

**src/cli/campaign_commands.py** (stage="campaign"):
- `campaign_app = typer.Typer(name="campaign", help="Build campaign structure with ad groups, keywords, and ad copy.")`
- `@campaign_app.callback(invoke_without_command=True)`
- Accepts client: Optional[str] = typer.Argument(None), dry_run: bool = typer.Option(False, "--dry-run")
- resolve_client, require_prerequisites("campaign") — requires "keywords" completed
- Load ClientProfile from `clients/{name}/intake/client_profile.json`
- Load keyword_data from `clients/{name}/keywords/keyword_data.json`
- Extract keyword_groups from keyword_data["groups"]
- Load digital_presence from `clients/{name}/research/site_crawl.json` if exists (wrap in DigitalPresence(site_crawl=SiteCrawl.model_validate(data))), else None
- Call `build_campaigns(profile, keyword_groups, digital_presence)`
- Write campaign plan to `clients/{name}/campaigns/campaign.json` as `plan.model_dump_json(indent=2)`
- Print summary: number of campaigns, ad groups, keywords
- complete_stage

**src/cli/validate_commands.py** (stage="validate"):
- `validate_app = typer.Typer(name="validate", help="Run pre-export validation checks on campaign plan.")`
- `@validate_app.callback(invoke_without_command=True)`
- Accepts client: Optional[str] = typer.Argument(None) — no dry_run needed for validate
- resolve_client, require_prerequisites("validate") — requires "campaign" completed
- Load campaign plan dict from `clients/{name}/campaigns/campaign.json` (as raw dict via json.load, NOT model — validate_campaign expects raw dict)
- Call `run_all_validations(plan_dict)` from scripts.validate_campaign
- Call `print_report(results)` — returns True/False
- If all passed: complete_stage
- If any failed: update_state(client_dir, "validate", "failed"), print warning, raise typer.Exit(1)

Import note for validate: `from scripts.validate_campaign import run_all_validations, print_report` — since scripts/ is at project root, use `sys.path.insert(0, str(PROJECT_ROOT))` if needed, OR import via the validate_campaign module path. Prefer adding `from src.utils.config import PROJECT_ROOT` and using `importlib` or direct path-based import:
```python
import importlib.util
spec = importlib.util.spec_from_file_location("validate_campaign", PROJECT_ROOT / "scripts" / "validate_campaign.py")
mod = importlib.util.module_from_spec(spec)
spec.loader.exec_module(mod)
run_all_validations = mod.run_all_validations
print_report = mod.print_report
```

**src/cli/report_commands.py** (stage="report"):
- `report_app = typer.Typer(name="report", help="Generate strategy report with analysis and recommendations.")`
- `@report_app.callback(invoke_without_command=True)`
- Accepts client: Optional[str] = typer.Argument(None), dry_run: bool = typer.Option(False, "--dry-run"), pdf: bool = typer.Option(True, "--pdf/--no-pdf", help="Generate PDF version")
- resolve_client, require_prerequisites("report") — requires "campaign" completed
- Load ClientProfile, keyword_data, CampaignPlan, competitors (if exists), digital_presence (if exists)
- For missing optional data (competitors, digital_presence), use empty defaults: competitors=[], digital_presence=DigitalPresence()
- Call `generate_strategy_report(profile, digital_presence, competitors, plan, keyword_data)`
- **DRY-04 implementation**: If dry_run is True, prepend a prominent warning to the markdown report:
  ```python
  if dry_run:
      dry_run_banner = (
          "---\n"
          "**WARNING: DRY RUN** - This report was generated using synthetic data. "
          "Keyword volumes, CPC estimates, and competitor data are simulated and do not "
          "reflect actual market conditions. Re-run without --dry-run for real data.\n"
          "---\n\n"
      )
      report_md = dry_run_banner + report_md
  ```
- Write markdown to `clients/{name}/reports/strategy_report.md`
- If pdf flag: call `export_pdf_report(profile, digital_presence, competitors, plan, keyword_data, str(reports_dir / "strategy_report.pdf"))`
  - If dry_run, the PDF will also contain the DRY RUN warning because it uses the same markdown content (generate_strategy_report is called inside export_pdf_report). To ensure the banner appears in PDF too, modify the approach: write the banner-prepended markdown to a temp variable, then call `generate_pdf_report(banner_md, str(pdf_path), title=title)` directly from pdf_generator instead of export_pdf_report (which regenerates the markdown without banner).
- complete_stage
- Print: "[green]Report generated at: {reports_dir}[/green]"

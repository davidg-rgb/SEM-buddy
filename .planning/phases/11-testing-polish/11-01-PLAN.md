  <action>
Create tests/test_auth.py with these test groups:

**1. OAuth tests (mock InstalledAppFlow):**
- test_get_oauth_scopes: returns list containing adwords scope
- test_run_oauth_flow_file_not_found: raises FileNotFoundError when client_secret.json missing
- test_run_oauth_flow_success: mock InstalledAppFlow.from_client_secrets_file and flow.run_local_server, verify returns flow.credentials. Use tmp_path to create a fake client_secret.json file.
- test_run_oauth_flow_port_retry: first two attempts raise OSError, third succeeds. Verify port increments (8080, 8081, 8082).
- test_run_oauth_flow_all_ports_fail: all 3 attempts raise OSError, verify AuthError raised with port range message.
- test_run_oauth_flow_user_denial: flow.run_local_server raises generic Exception, verify AuthError raised.

**2. Credentials tests (mock keyring entirely):**
- Use monkeypatch to replace keyring.get_password, keyring.set_password, keyring.delete_password.
- Use tmp_path for TOKEN_FILE and KEY_FILE by monkeypatching the module-level constants.
- test_store_and_load_tokens_keyring: store via keyring succeeds, load returns same token/refresh_token/client_id/client_secret.
- test_store_tokens_keyring_fallback_to_file: keyring.set_password raises, verify TOKEN_FILE created on disk.
- test_load_tokens_returns_none_when_empty: no keyring data, no file, returns None.
- test_clear_tokens: store tokens, clear, verify load returns None.
- test_credentials_roundtrip_with_expiry: store creds with expiry datetime, load back, verify expiry preserved (timezone-aware UTC).

**3. Token refresh tests (mock google.auth):**
- test_ensure_valid_token_already_valid: creds.valid=True, creds.expired=False, returns same object.
- test_ensure_valid_token_refreshes_expired: creds.expired=True, mock credentials.refresh() to succeed, verify store_tokens called.
- test_ensure_valid_token_no_refresh_token: creds with refresh_token=None, raises AuthError.
- test_ensure_valid_token_refresh_error: mock refresh() raising RefreshError, verify AuthError.
- test_check_expiry_with_future_expiry: returns valid=True, minutes_remaining > 0.
- test_check_expiry_with_no_expiry: returns expires_at=None, minutes_remaining=None.

**4. Google Ads auth tests (mock load_tokens, config_manager):**
- test_build_google_ads_config: verify dict has developer_token, client_id, client_secret, refresh_token, use_proto_plus=True.
- test_build_google_ads_config_strips_hyphens: login_customer_id "123-456-7890" becomes "1234567890".
- test_build_google_ads_config_no_login_id: login_customer_id=None means key absent from dict.
- test_get_google_ads_client_no_tokens: mock load_tokens returning None, verify AuthError.
- test_get_google_ads_client_no_developer_token: mock load_tokens returning valid creds, config_manager.get_value("developer_token") returns None, verify AuthError.

Create mock Credentials using unittest.mock.MagicMock or by constructing google.oauth2.credentials.Credentials directly with test values (token="test-token", refresh_token="test-refresh", client_id="test-id.apps.googleusercontent.com", client_secret="test-secret", token_uri="https://oauth2.googleapis.com/token").

For ensure_valid_token tests, mock the credentials object's .valid, .expired, .refresh_token, and .refresh() attributes.

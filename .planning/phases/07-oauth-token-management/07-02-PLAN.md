1. Create `src/auth/google_ads_auth.py`:

   `build_google_ads_config(credentials: Credentials, developer_token: str, login_customer_id: str | None = None) -> dict`:
   - Return dict with keys: `developer_token`, `client_id` (from credentials.client_id), `client_secret` (from credentials.client_secret), `refresh_token` (from credentials.refresh_token), `use_proto_plus` (True), and optionally `login_customer_id` (only if not None, strip hyphens)
   - This dict is compatible with `GoogleAdsClient.load_from_dict()`

   `get_google_ads_client(customer_id: str | None = None) -> GoogleAdsClient`:
   - Call `load_tokens()` — if None, raise `AuthError("Not authenticated. Run 'sem auth login' first.")`
   - Call `ensure_valid_token(credentials)` to refresh if needed
   - Read `developer_token` via `config_manager.get_value("developer_token")` — if None, raise `AuthError("No developer token configured. Run 'sem config set developer_token YOUR_TOKEN'.")`
   - Read `mcc_customer_id` via `config_manager.get_value("mcc_customer_id")` — use as login_customer_id
   - Call `build_google_ads_config(credentials, developer_token, mcc_customer_id)`
   - Return `GoogleAdsClient.load_from_dict(config_dict)`

   Imports: `from google.ads.googleads.client import GoogleAdsClient`, `from google.oauth2.credentials import Credentials`, `from src.auth import AuthError`, `from src.auth.credentials import load_tokens`, `from src.auth.token_refresh import ensure_valid_token`, `from src.utils import config_manager`

2. Create `src/cli/auth_commands.py`:

   Module-level: `auth_app = typer.Typer(name="auth", help="OAuth authentication and token management.")`

   `@auth_app.command("setup")` — `def setup()`:
   - Print a rich-formatted step-by-step guide using `rich.console.Console` and `rich.panel.Panel`:
     - Step 1: Go to https://console.cloud.google.com/ and create a new project (name: "SEM Master")
     - Step 2: Enable the Google Ads API at APIs & Services > Library
     - Step 3: Create OAuth 2.0 credentials at APIs & Services > Credentials > Create Credentials > OAuth client ID > Desktop app
     - Step 4: Download the client_secret.json file and save to `~/.sem-master/credentials/client_secret.json`
     - Step 5: Apply for a Google Ads API developer token at https://ads.google.com/aw/apicenter (under MCC account)
     - Step 6: Once you have the developer token, run: `sem config set developer_token YOUR_TOKEN`
     - Step 7: Set your MCC customer ID: `sem config set mcc_customer_id 123-456-7890`
     - Step 8: Run `sem auth login` to authenticate
   - Use `rich.markdown.Markdown` or `Panel` sections with numbered steps
   - Print `CONFIG_DIR / "credentials" / "client_secret.json"` as the expected path

   `@auth_app.command("login")` — `def login()`:
   - Determine client_secret_path: `CONFIG_DIR / "credentials" / "client_secret.json"`
   - If not exists: print error "[red]client_secret.json not found at {path}[/red]" + "Run 'sem auth setup' for instructions." + raise typer.Exit(1)
   - Print "[bold]Starting OAuth flow...[/bold] A browser window will open."
   - Try `run_oauth_flow(client_secret_path)`
   - On success: call `store_tokens(credentials)`, print "[green]Authentication successful! Tokens stored securely.[/green]"
   - On AuthError: print "[red]Authentication failed: {e}[/red]", raise typer.Exit(1)

   `@auth_app.command("status")` — `def status()`:
   - Call `load_tokens()` — if None: print "[yellow]Not authenticated.[/yellow] Run 'sem auth login'." + raise typer.Exit(0)
   - Call `check_expiry(credentials)` to get validity info
   - Read `mcc_customer_id` from config_manager.get_value("mcc_customer_id")
   - Read `developer_token` from config_manager.get_value("developer_token")
   - Print a Rich Panel with:
     - "Authenticated: [green]Yes[/green]" or "[red]Token expired[/red]"
     - "Expires: {expires_at}" and "Minutes remaining: {minutes_remaining}"
     - "MCC Customer ID: {mcc_customer_id or 'Not set'}"
     - "Developer Token: {'Configured' if developer_token else 'Not set'}"

   `@auth_app.command("logout")` — `def logout()`:
   - Call `clear_tokens()`
   - Print "[green]All credentials cleared.[/green]"

   Imports: `typer`, `from rich.console import Console`, `from rich.panel import Panel`, `from rich import print as rprint`, `from src.auth.oauth import run_oauth_flow`, `from src.auth.credentials import store_tokens, load_tokens, clear_tokens`, `from src.auth.token_refresh import check_expiry`, `from src.auth import AuthError`, `from src.utils.config_manager import CONFIG_DIR`, `from src.utils import config_manager`

   ```python
   if verify_mcc:
       try:
           from src.auth.google_ads_auth import get_google_ads_client
           client = get_google_ads_client()
           # Strip hyphens from customer_id for API call
           clean_id = customer_id.replace("-", "")
           # Use CustomerService to verify accessibility
           ga_service = client.get_service("CustomerService")
           # accessible_customers returns list of resource names
           accessible = ga_service.list_accessible_customers()
           accessible_ids = [r.split("/")[-1] for r in accessible.resource_names]
           if clean_id not in accessible_ids:
               rprint(f"[yellow]Warning: Account {customer_id} is not accessible under your MCC. "
                      f"Check that the account is linked to your MCC.[/yellow]")
           else:
               rprint(f"[green]Verified: Account {customer_id} is accessible under MCC.[/green]")
       except Exception as exc:
           rprint(f"[yellow]Could not verify MCC access: {exc}[/yellow]")
           rprint("[dim]Account was created locally. Verify MCC access manually.[/dim]")
   ```

   Import `AuthError` at the top: `from src.auth import AuthError` (add to existing imports).
   Note: The `from src.auth.google_ads_auth import get_google_ads_client` is done inside the if-block to avoid import errors when auth is not configured.

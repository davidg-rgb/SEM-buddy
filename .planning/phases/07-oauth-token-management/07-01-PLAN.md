4. Create `src/auth/credentials.py` with these functions:

   Constants at module level:
   ```python
   SERVICE_NAME = "sem-master"
   TOKEN_USERNAME = "oauth-tokens"
   TOKEN_FILE = CONFIG_DIR / "credentials" / "tokens.enc"
   KEY_FILE = CONFIG_DIR / "credentials" / ".keyfile"
   ```

   `_get_or_create_key() -> bytes`:
   - Try `keyring.get_password(SERVICE_NAME, "fernet-key")`
   - If found, return `base64.urlsafe_b64decode(stored_key)`
   - If not found (or keyring raises), generate via `Fernet.generate_key()`
   - Try storing in keyring via `keyring.set_password(SERVICE_NAME, "fernet-key", base64.urlsafe_b64encode(key).decode())`
   - If keyring storage fails, write key to `KEY_FILE` with 0o600 permissions (on Windows just write it)
   - Return the key bytes

   `_credentials_to_dict(credentials: Credentials) -> dict`:
   - Extract: token, refresh_token, token_uri, client_id, client_secret, expiry (as ISO string or None)
   - Return as dict

   `_dict_to_credentials(data: dict) -> Credentials`:
   - Build `google.oauth2.credentials.Credentials` from dict fields
   - Parse expiry ISO string back to datetime if present
   - Return Credentials object

   `store_tokens(credentials: Credentials) -> None`:
   - Convert credentials to dict via `_credentials_to_dict`
   - Serialize to JSON string
   - Primary: try `keyring.set_password(SERVICE_NAME, TOKEN_USERNAME, json_str)`
   - Fallback: if keyring fails, encrypt with Fernet using `_get_or_create_key()`, write to `TOKEN_FILE`
   - Log which backend was used via a module-level logger

   `load_tokens() -> Credentials | None`:
   - Primary: try `keyring.get_password(SERVICE_NAME, TOKEN_USERNAME)`
   - If found, parse JSON, return `_dict_to_credentials(data)`
   - Fallback: if keyring returns None or fails, check `TOKEN_FILE.exists()`
   - If file exists, read, decrypt with Fernet using `_get_or_create_key()`, parse JSON
   - If any error (corrupt data, wrong key), return `None`
   - If neither source has tokens, return `None`

   `clear_tokens() -> None`:
   - Try `keyring.delete_password(SERVICE_NAME, TOKEN_USERNAME)` (ignore errors)
   - Try `keyring.delete_password(SERVICE_NAME, "fernet-key")` (ignore errors)
   - If `TOKEN_FILE.exists()`: `TOKEN_FILE.unlink()`
   - If `KEY_FILE.exists()`: `KEY_FILE.unlink()`

   All imports: `from pathlib import Path`, `import json`, `import logging`, `import base64`, `from datetime import datetime, timezone`, `from google.oauth2.credentials import Credentials`, `from cryptography.fernet import Fernet`, `import keyring`, `from src.utils.config_manager import CONFIG_DIR`, `from src.auth import StorageError`

  <action>
Create `src/auth/token_refresh.py` with two functions:

`ensure_valid_token(credentials: Credentials) -> Credentials`:
- If `credentials.valid` and not `credentials.expired`: return credentials as-is
- If `credentials.expired` and `credentials.refresh_token` is not None:
  - Try `credentials.refresh(google.auth.transport.requests.Request())`
  - On success: call `store_tokens(credentials)` to persist refreshed tokens, return credentials
  - On `google.auth.exceptions.RefreshError` as e: raise `AuthError(f"Token refresh failed — re-authenticate with 'sem auth login': {e}")`
  - On network errors (`Exception`): raise `AuthError(f"Network error during token refresh: {e}")`
- If no refresh_token: raise `AuthError("No refresh token available — re-authenticate with 'sem auth login'")`

`check_expiry(credentials: Credentials) -> dict`:
- Build result dict with keys: `valid` (bool), `expires_at` (datetime or None), `minutes_remaining` (int or None)
- If `credentials.expiry` is not None:
  - `expires_at = credentials.expiry`
  - `minutes_remaining = max(0, int((credentials.expiry - datetime.now(timezone.utc)).total_seconds() / 60))`
  - `valid = not credentials.expired`
- If `credentials.expiry` is None:
  - `valid = credentials.valid`, `expires_at = None`, `minutes_remaining = None`
- Return the dict

Imports: `from datetime import datetime, timezone`, `from google.oauth2.credentials import Credentials`, `import google.auth.transport.requests`, `import google.auth.exceptions`, `from src.auth import AuthError`, `from src.auth.credentials import store_tokens`

**1. Create `src/cli/config_commands.py`** per ARCHITECTURE.md section 6.8:

```python
"""CLI commands for global configuration management."""

import typer
from rich.console import Console
from rich.table import Table
from rich import print as rprint
import yaml

from src.utils.config_manager import load_config, get_value, set_value, CONFIG_PATH

config_app = typer.Typer(name="config", help="Manage global configuration.")
console = Console()
```

Commands (decorated with `@config_app.command()`):

`show()`:
- Load full config via `load_config()`
- Print config path: `console.print(f"Config: {CONFIG_PATH}")`
- Print config as formatted YAML using `yaml.dump(config, allow_unicode=True, default_flow_style=False)`
- Use `rich.syntax.Syntax` for YAML highlighting if desired, or just `console.print`

`set(key: str = typer.Argument(..., help="Config key (dot-notation, e.g., defaults.industry)"), value: str = typer.Argument(..., help="Value to set"))`:
- Attempt to parse value: try int(), try float(), check "true"/"false" for bool, else keep as string
- Also handle "null"/"none" → set as None
- Call `set_value(key, parsed_value)`
- Print confirmation: `rprint(f"[green]Set {key} = {parsed_value}[/green]")`

`edit()`:
- Print path to config file: `console.print(f"Edit: {CONFIG_PATH}")`
- Attempt to open with `typer.launch(str(CONFIG_PATH))` — opens in default editor
- Per ARCHITECTURE.md: falls back to printing path if no editor available

**2. Create `src/cli/accounts_commands.py`** per ARCHITECTURE.md section 6.3:

```python
"""CLI commands for client account management."""

import typer
from rich.console import Console
from rich.table import Table
from rich.panel import Panel
from rich import print as rprint

from src.accounts.manager import (
    create_account, list_accounts, get_account,
    remove_account, set_active_client, get_active_client,
)
from src.accounts.state import get_pipeline_state, get_next_stage
from src.utils.config import CLIENTS_DIR

accounts_app = typer.Typer(name="accounts", help="Manage client accounts.")
console = Console()
```

Commands:

`list_cmd()` (register as `@accounts_app.command("list")`):
- Call `list_accounts()` to get all ManagedAccount objects
- If empty, print `"No accounts registered. Use 'sem accounts add' to create one."`
- Build a Rich Table with columns: Name, Customer ID, Industry, Budget (SEK), Status
- Status = active client gets a green checkmark, others blank
- For pipeline status, call `get_next_stage(CLIENTS_DIR / acct.name)` wrapped in try/except
- Print the table

`add(name: str = typer.Argument(..., help="Client slug (kebab-case)"), customer_id: str = typer.Argument(..., help="Google Ads Customer ID (XXX-XXX-XXXX)"), industry: str = typer.Option(None, "--industry", "-i", help="Industry key"), budget: int = typer.Option(None, "--budget", "-b", help="Monthly budget in SEK"))`:
- Call `create_account(name, customer_id, industry=industry, budget_sek=budget)`
- Catch ValueError for duplicate name or validation errors, print with `rprint(f"[red]Error: {e}[/red]")` and `raise typer.Exit(1)`
- On success: `rprint(f"[green]Added client '{name}' (Customer ID: {customer_id})[/green]")`

`remove(name: str = typer.Argument(..., help="Client slug"), no_archive: bool = typer.Option(False, "--no-archive", help="Delete permanently instead of archiving"))`:
- Confirm with `typer.confirm(f"Remove client '{name}'?", abort=True)`
- Call `remove_account(name, archive=not no_archive)`
- Print success message indicating archived or deleted

`switch(name: str = typer.Argument(..., help="Client slug to set as active"))`:
- Call `set_active_client(name)`
- Catch FileNotFoundError, print error and exit
- On success: `rprint(f"[green]Active client: {name}[/green]")`

`info(name: str = typer.Argument(None, help="Client slug (defaults to active client)"))`:
- If name is None, call `get_active_client()`. If still None, print "No active client" and exit
- Call `get_account(name)` — catch FileNotFoundError
- Call `get_pipeline_state(CLIENTS_DIR / name)` wrapped in try/except
- Build a Rich Panel with account details: display_name, customer_id, industry, budget, website, contact, created_at
- Add pipeline stage status table within the panel
- Print with `console.print(panel)`

All error messages use `[red]` Rich markup. All success messages use `[green]`. This satisfies CLI-05 (rich formatting).

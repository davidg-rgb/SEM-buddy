Import `CLIENTS_DIR` from `src.utils.config` (this is `PROJECT_ROOT / "clients"`).

**Functions:**

`create_account(name: str, customer_id: str, industry: str = None, budget_sek: int = None, display_name: str = None) -> ManagedAccount`:
- If `display_name` is None, derive from name (capitalize, replace hyphens with spaces)
- Create ManagedAccount model (validates name and customer_id via Pydantic)
- Check if `CLIENTS_DIR / name` already exists — raise `ValueError("Client '{name}' already exists")` if so
- Create directory tree: `clients/{name}/` with subdirs: `intake/`, `research/`, `competitors/`, `keywords/`, `campaigns/`, `exports/`, `reports/`, `audits/`
- Call `write_account_config(client_dir, account)` to write account.yaml
- Call `initialize_state(client_dir)` to create workflow_state.json
- Return the ManagedAccount

`list_accounts() -> list[ManagedAccount]`:
- Iterate directories in CLIENTS_DIR (skip `_archived`, skip non-directories)
- For each, call `read_account_config(client_dir)` wrapped in try/except (skip dirs without account.yaml)
- Return sorted by name

`get_account(name: str) -> ManagedAccount`:
- Check `CLIENTS_DIR / name` exists, raise `FileNotFoundError(f"Client '{name}' not found")` if not
- Return `read_account_config(CLIENTS_DIR / name)`

`remove_account(name: str, archive: bool = True) -> None`:
- Check client exists via get_account (raises if not found)
- If archive: create `CLIENTS_DIR / "_archived"` dir, move `CLIENTS_DIR / name` to `CLIENTS_DIR / "_archived" / name` using `shutil.move`
- If not archive: delete with `shutil.rmtree`
- If removed client was active, set active_client to None

`set_active_client(name: str) -> None`:
- Verify client exists via get_account (raises if not found)
- Call `config_manager.set_value("active_client", name)`

`get_active_client() -> str | None`:
- Call `config_manager.get_value("active_client")`
- Return the value (may be None)

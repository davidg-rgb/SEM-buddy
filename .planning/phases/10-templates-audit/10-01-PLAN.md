  <action>
Create `src/templates/` package with three files:

**src/templates/__init__.py** — Empty package init.

**src/templates/manager.py** — Template CRUD operations:

1. Define `TEMPLATES_DIR = CONFIG_DIR / "templates"` (import CONFIG_DIR from src.utils.config_manager).

2. Define a Pydantic model `CampaignTemplate(BaseModel)`:
   - `name: str` — template slug (kebab-case)
   - `description: str = ""`
   - `created_at: datetime`
   - `source_client: str` — original client name (for reference only)
   - `source_industry: str = ""`
   - `campaigns: list[dict]` — serialized campaign structures with client data stripped
   - `sitelinks: list[dict] = []`
   - `callouts: list[dict] = []`
   - `snippets: list[dict] = []`
   - `call_extensions: list[dict] = []`

3. `save_template(name: str, campaign_plan: CampaignPlan, client: ClientProfile, description: str = "") -> Path`:
   - Create TEMPLATES_DIR if missing
   - Strip client-specific data via `_strip_client_specifics(campaign_plan, client)`:
     - Replace `client.business_name` with placeholder `{Foretag}` in all ad headline/description texts
     - Replace `client.website_url` host with placeholder `{website}` in final_url fields
     - Clear geo_targets (will be re-populated from target client)
     - Keep campaign structure, ad group themes, keyword match types, bid strategies
   - Build CampaignTemplate model with the stripped data (use `model_dump()` on campaigns)
   - Write to `TEMPLATES_DIR / f"{name}.json"` as JSON with indent=2, encoding utf-8
   - Return the path

4. `load_template(name: str) -> CampaignTemplate`:
   - Read from `TEMPLATES_DIR / f"{name}.json"`
   - Raise `FileNotFoundError` with message `f"Template '{name}' not found"` if missing
   - Return validated CampaignTemplate

5. `list_templates() -> list[dict]`:
   - Glob `TEMPLATES_DIR / "*.json"`, parse each
   - Return list of dicts: `{"name", "description", "created_at", "source_client", "source_industry"}`
   - Return empty list if TEMPLATES_DIR doesn't exist

6. `delete_template(name: str) -> None`:
   - Delete `TEMPLATES_DIR / f"{name}.json"`
   - Raise `FileNotFoundError` with message if missing

**src/templates/adapter.py** — Template adaptation:

1. `apply_template(template: CampaignTemplate, client: ClientProfile, keyword_groups: dict | None = None) -> CampaignPlan`:
   - For each campaign dict in template.campaigns:
     - Replace `{Foretag}` with `client.business_name` in all text fields
     - Replace `{website}` with `str(client.website_url)` in final_url fields
     - Set `geo_targets` from `client.geographic_targets`
     - If keyword_groups provided and ad group themes match keys in keyword_groups, update keywords from the new groups
     - Regenerate ad copy using `generate_headlines()` and `generate_descriptions()` from ad_copy_generator for each ad group, using the ad group's theme and the client profile. Build RSAs via `generate_rsa()`. This ensures ad copy is tailored to the new client.
   - Reconstruct CampaignPlan from the adapted campaign dicts, including template sitelinks/callouts/snippets/call_extensions (with `{Foretag}` and `{website}` replaced)
   - Return the new CampaignPlan

**src/cli/template_commands.py** — Typer command group following the exact pattern in campaign_commands.py:

1. Create `template_app = typer.Typer(name="templates", help="Save and reuse campaign templates.")` and `console = Console()`.

2. `@template_app.command("list")` — `list_cmd() -> None`:
   - Call `list_templates()` from src.templates.manager
   - If no templates, print `[yellow]No templates saved yet.[/yellow]` and return
   - Print a Rich Table with columns: Name, Description, Industry, Source Client, Created
   - Format `created_at` as `YYYY-MM-DD`

3. `@template_app.command("save")` — `save_cmd(name: str, client: Optional[str], description: str = typer.Option("", help="Template description.")) -> None`:
   - Use `resolve_client(client)` from stage_helpers to get (name, client_dir)
   - Load `client_dir / "campaigns" / "campaign.json"` into CampaignPlan via `CampaignPlan.model_validate_json()`
   - If campaign.json missing, print red error and `raise typer.Exit(1)`
   - Load `client_dir / "intake" / "client_profile.json"` into ClientProfile
   - Call `save_template(name, plan, profile, description)` from src.templates.manager
   - Print green success: `[green]Template '{name}' saved from client '{client_name}'.[/green]`

4. `@template_app.command("load")` — `load_cmd(name: str, client: Optional[str]) -> None`:
   - Use `resolve_client(client)` to get target (client_name, client_dir)
   - Call `load_template(name)` — catch FileNotFoundError, print red error, exit 1
   - Load target client profile from `client_dir / "intake" / "client_profile.json"` — if missing, print error, exit 1
   - Optionally load `client_dir / "keywords" / "keyword_data.json"` for keyword_groups (don't fail if missing)
   - Call `apply_template(template, profile, keyword_groups)` from src.templates.adapter
   - Write adapted plan to `client_dir / "campaigns" / "campaign.json"` via `plan.model_dump_json(indent=2)`
   - Print green success panel showing campaign/ad-group/keyword counts

5. `@template_app.command("delete")` — `delete_cmd(name: str) -> None`:
   - Call `delete_template(name)` — catch FileNotFoundError, print red error, exit 1
   - Print green success: `[green]Template '{name}' deleted.[/green]`

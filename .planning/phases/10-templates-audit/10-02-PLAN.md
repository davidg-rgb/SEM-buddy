**src/audit/fetcher.py** — Live campaign data retrieval:

1. Import `get_ads_service` from `src.apis.google_ads`, `AuthError` from `src.auth`, `GoogleAdsApiError` from `src.apis.errors`.

2. `async def fetch_live_campaigns(customer_id: str, dry_run: bool = False, campaign_ids: list[str] | None = None) -> list[dict]`:
   - Get service via `get_ads_service(customer_id, dry_run=dry_run)`
   - Call `service.get_campaigns()` to get all campaigns
   - If `campaign_ids` provided, filter to only those IDs
   - For each campaign, call `service.get_ad_groups(campaign["id"])`
   - For each ad group, call `service.get_keywords(ad_group["id"])` and `service.get_ads(ad_group["id"])`
   - Return a list of enriched campaign dicts:
     ```python
     {
         "id": str,
         "name": str,
         "status": str,
         "advertising_channel_type": str,
         "campaign_budget": str,
         "ad_groups": [
             {
                 "id": str, "name": str, "status": str, "type": str,
                 "keywords": [{"text": str, "match_type": str, "status": str}],
                 "ads": [{"headlines": [str], "descriptions": [str], "status": str}]
             }
         ]
     }
     ```
   - Note: GoogleAdsService methods are async, so use `await` and `import asyncio`

3. `async def fetch_keyword_performance(customer_id: str, dry_run: bool = False, date_range: str = "LAST_30_DAYS") -> list[dict]`:
   - For the real service, this would use GAQL to get keyword performance metrics
   - For now, if dry_run=True, return synthetic performance data (impressions, clicks, ctr, avg_cpc, conversions for common Swedish keywords)
   - If dry_run=False, use service._search() with a GAQL query: `SELECT ad_group_criterion.keyword.text, metrics.impressions, metrics.clicks, metrics.ctr, metrics.average_cpc, metrics.conversions FROM keyword_view WHERE segments.date DURING {date_range}`
   - Wrap in try/except to handle API errors gracefully

4. Add a sync wrapper `def fetch_live_campaigns_sync(...)` that calls `asyncio.run(fetch_live_campaigns(...))` for CLI convenience.

**src/audit/comparator.py** — Diff engine:

1. Import `CampaignPlan` from `src.models.campaign`.

2. `def compare(live_campaigns: list[dict], recommended_plan: CampaignPlan) -> dict`:
   - Build sets of campaign names from both live and recommended
   - `missing_campaigns`: names in recommended but not in live (campaigns the operator should create)
   - `extra_campaigns`: names in live but not in recommended (campaigns not in the plan — could be legacy)
   - `keyword_gaps`: for campaigns that exist in both (matched by name), collect recommended keywords not found in live ad groups. Return list of dicts: `{"campaign": str, "ad_group": str, "keyword": str, "match_type": str}`
   - `keyword_waste`: live keywords not in recommended plan. Same dict format.
   - `ad_copy_diffs`: for matched campaigns+ad groups, compare headline/description texts. Return list of dicts: `{"campaign": str, "ad_group": str, "type": "headline"|"description", "recommended": str, "live": str | None}`
   - `budget_diffs`: for matched campaigns, compare budget_sek_daily (recommended) vs campaign_budget (live). Return list of dicts: `{"campaign": str, "recommended_budget": float, "live_budget": str}`
   - `bid_strategy_diffs`: for matched campaigns, compare bid_strategy. Return list of dicts: `{"campaign": str, "recommended": str, "live": str}`
   - Campaign name matching should be case-insensitive
   - Return dict with all the above keys

3. `def format_audit_report(diff: dict, client_name: str) -> str`:
   - Generate a markdown report string
   - Title: `# Kampanjgranskning: {client_name}` (Swedish heading)
   - Date line: current date
   - Section `## Sammanfattning` with counts: X saknade kampanjer, Y extra kampanjer, Z saknade sokord, etc.
   - Section `## Saknade kampanjer` — table of missing campaigns
   - Section `## Extra kampanjer (ej i plan)` — table of extra campaigns
   - Section `## Sokordsluckor` — table of keyword gaps (campaign, ad group, keyword, match type)
   - Section `## Potentiellt sokordsslöseri` — table of keywords in live but not recommended
   - Section `## Annonskopieringsskillnader` — table of ad copy diffs
   - Section `## Budgetskillnader` — table of budget diffs
   - Section `## Budstrategiskillnader` — table of bid strategy diffs
   - Use Swedish section headers throughout
   - Return the full markdown string

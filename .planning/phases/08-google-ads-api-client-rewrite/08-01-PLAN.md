```python
class ApiError(Exception):
    """Base class for all API errors."""
    def __init__(self, message: str, hint: str = ""):
        self.message = message
        self.hint = hint
        super().__init__(message)

class GoogleAdsApiError(ApiError):
    """Google Ads API returned an error."""
    # Store the original google.ads.googleads.errors.GoogleAdsFailure if available
    def __init__(self, message: str, hint: str = "", failure=None):
        self.failure = failure
        super().__init__(message, hint)

class QuotaExceededError(ApiError):
    """API rate limit or quota exceeded."""
    def __init__(self, message: str = "Google Ads API quota exceeded.",
                 hint: str = "Wait and retry, or check your API quota at console.cloud.google.com."):
        super().__init__(message, hint)

class SpyFuApiError(ApiError):
    """SpyFu API error."""

class ValueSerpApiError(ApiError):
    """ValueSERP API error."""
```

**Class: GoogleAdsService**
- `__init__(self, customer_id: str)`: Store customer_id (strip hyphens). Call `get_google_ads_client()` from src.auth.google_ads_auth to get the authenticated GoogleAdsClient. Store as `self._client`. Catch AuthError and re-raise as-is (callers handle it). Store `self._ga_service = self._client.get_service("GoogleAdsService")`.

- `async get_keyword_ideas(self, seeds: list[str], geo_id=2752, language_id=1053, page_size=1000) -> list[dict]`:
  Use KeywordPlanIdeaService. Build GenerateKeywordIdeasRequest with customer_id, language resource `languageConstants/{language_id}`, geo resource `geoTargetConstants/{geo_id}`, keyword_seed.keywords = seeds, page_size. Call generate_keyword_ideas(). Return list of dicts: `{"text": str, "avg_monthly_searches": int, "competition": str, "avg_cpc_micros": int, "competition_index": int}`. Wrap google.ads.googleads.errors.GoogleAdsFailure in GoogleAdsApiError. Detect RESOURCE_EXHAUSTED status for QuotaExceededError.

- `async get_search_volumes(self, keywords: list[str], geo_id=2752, language_id=1053) -> list[dict]`:
  Same as get_keyword_ideas but filter results to only keywords present in the input list. Return dicts: `{"keyword": str, "monthly_searches": int, "avg_cpc_sek": float, "competition": str}`. Convert avg_cpc_micros to SEK (divide by 1_000_000).

- `async get_campaigns(self, include_removed=False) -> list[dict]`:
  GAQL query: `SELECT campaign.id, campaign.name, campaign.status, campaign.advertising_channel_type, campaign.campaign_budget FROM campaign` (add `WHERE campaign.status != 'REMOVED'` unless include_removed). Return list of campaign dicts.

- `async get_ad_groups(self, campaign_id: str) -> list[dict]`:
  GAQL: `SELECT ad_group.id, ad_group.name, ad_group.status, ad_group.type FROM ad_group WHERE ad_group.campaign = 'customers/{cid}/campaigns/{campaign_id}'`. Return list of ad group dicts.

- `async get_keywords(self, ad_group_id: str = None) -> list[dict]`:
  GAQL on ad_group_criterion resource: `SELECT ad_group_criterion.keyword.text, ad_group_criterion.keyword.match_type, ad_group_criterion.status FROM ad_group_criterion WHERE ad_group_criterion.type = 'KEYWORD'`. Filter by ad_group if provided. Return list of keyword dicts.

- `async get_ads(self, ad_group_id: str = None) -> list[dict]`:
  GAQL on ad_group_ad resource: `SELECT ad_group_ad.ad.responsive_search_ad.headlines, ad_group_ad.ad.responsive_search_ad.descriptions, ad_group_ad.status FROM ad_group_ad WHERE ad_group_ad.ad.type = 'RESPONSIVE_SEARCH_AD'`. Filter by ad_group if provided. Return list of ad dicts.

- `async get_account_info(self) -> dict`:
  GAQL: `SELECT customer.id, customer.descriptive_name, customer.currency_code, customer.time_zone FROM customer LIMIT 1`. Return dict with id, name, currency, timezone.

**Error handling for ALL methods:**
Wrap SDK calls in try/except:

- `google.api_core.exceptions.GoogleAPIError` -> raise GoogleAdsApiError with str(e) and generic hint.

Private method that calls `self._ga_service.search(customer_id=self._customer_id, query=query)` and returns list of rows. All GAQL methods use this. Error wrapping happens here once.

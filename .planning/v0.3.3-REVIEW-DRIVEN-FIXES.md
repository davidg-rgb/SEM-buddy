# v0.3.3 — Review-Driven Fixes

> **Shipped:** 2026-05-20
> **Status:** Done. 600 tests pass, 4,580 RSAs generated across 963 ad groups (post-cleaning), zero Severity-0 findings remaining from the consolidated review.
> **Driver:** Four parallel `sem-ad-copy` reviewer agents audited 95 RSAs (10 published + 85 sampled from the new generator). Their consolidated findings are in `.planning/review/CONSOLIDATED-REVIEW.md`.

---

## Problem

The v0.3.2 multi-variant generator was structurally correct but shipped four hard bugs and ~15 pattern-level slop issues that prevented clean serving:

- **S0-1:** `from_price=null` rendered visible `$ ` and "from in" fragments
- **S0-2:** Louisville sku/name inverted (`sku="Louisville", name="SDF"`); 3 non-IATA SKUs (NY, LON-Heathrow, Louisville) shipped customer-facing
- **S0-4:** "ATOL-style protection" + "Was full price, now -X%" in every social_proof/discount_led variant — ASA/FTC compliance risks
- **S0-5/S0-6:** Long-name destinations (PKC at 42 chars) produced "Avoid Petropavlovsk-Kamchats" (telling the searcher to avoid the place) and descriptions ending mid-clause ("free 24h" missing "cancellation", "save the difference on every" missing "leg")
- **S1-1 to S1-14:** Banned phrases, fake-scarcity, false-anchor compliance issues, generic H3 CTAs, IATA codes in customer-facing copy, low-discount variants ≤14% generating CTR-negative copy

---

## Solution

Spawned three parallel specialist agents — **Patterns**, **Generator**, **Catalog** — each owning a non-overlapping file scope. Each was briefed with the full consolidated review plus the `sem-ad-copy` skill specification. Integration pass + targeted post-fixes done by orchestrator.

### Agent A: Patterns refactor (`data/en/ad_copy_patterns.json` v3)

- **Banned phrases stripped:** "Top-rated travel agent", "ATOL-style protection", "Was full price, now -X%", "Today only: X% off", "Final seats", "Last-minute", "Cheap {name} flights", "Member, IATA accredited", "Price Drop Alerts Free", any " - " sentence-pause hyphen.
- **Schema additions:** `requires_from_price`, `long_name_fallback`, `requires_was_minus_now` per-pattern flags.
- **Variant-specific tail headlines:** Each variant now has 2 unique H14/H15 (was: all 5 variants shared identical strings, 27% of every variant was duplicate input to Google's RSA optimizer).
- **Pattern-interrupt H4:** Each variant carries `pattern_interrupt_h4` — Flightnetwork-specific moats ("Pay the airline price", "Free 24h cancellation") elevated to position 4 to break OTA parity.
- **Role-specific pinned H3:** Replaces the generic `"Compare fares today"` that appeared on every v1.
- **New top-level `long_name_fallback_patterns` block:** Compact SKU-based patterns the generator switches to when `len(name) >= 18`.
- **Real urgency** replaces fake scarcity: "Fares update every hour" / "Real-time inventory" instead of "Final seats" and undated countdowns.

### Agent B: Generator refactor (`src/generators/ad_copy_generator.py` + `llm_ad_copy.py`)

- **Null-safe price interpolation:** `_fill_pattern` early-skips `requires_from_price` patterns when null; final regex sweep rejects any line carrying naked `$` or trailing `from `.
- **`MIN_DISCOUNT_PCT_FOR_DISCOUNT_LED = 0.15`:** Discount variant only emits at >=15%. Below threshold, the ad group gets 4 variants (no `discount_led`) — closing the 5%/8%/11% CTR-negative issue.
- **`MAX_DISCOUNT_PCT_HEADLINES = 5`:** Caps discount-mention repetition to avoid Google's semantic-similarity dampening.
- **`IATA_HOUSEHOLD_CODES`:** Allowlist of 54 customer-recognized codes (LAX/JFK/LHR/CDG/...). Non-household SKUs render as empty in customer-facing copy.
- **Long-name fallback:** `_resolve_display_name(product, max_chars)` picks `short_name` → IATA code → comma-segment fallback. Long-name destinations now use `long_name_fallback_patterns` instead of mid-word truncating.
- **Improved `_fit_to_limit`:** Extended trailing-incomplete-fragment list ("free", "cancellation", "24h", "60", "policy", "support", "hour", "every", "seconds", "side", numbers); aggressive ≥50%-of-budget rejection guard so the caller skips rather than ships a fragment.
- **Computed `{was_price}` anchor:** When `from_price` + `discount_pct` both known, generator computes `was_price = from_price / (1 - discount_pct)` and emits `"Was $X, now $Y"` — replaces the FTC-risky "Was full price, now -X%".
- **Stop-slop post-pass:** Hyphen-as-em-dash → comma, ASCII → diacritic restoration ("Sao Paulo" → "São Paulo"), double-space collapse.
- **LLM prompt rewrites:** Banned-list extended; variant-specific instructions emphasize real proof points only (no fabricated ATOL claims) and computed anchors instead of "was full price".
- **Title-case keyword fallback:** `_title_case_keyword()` so "cheap flights to hartford" → "Cheap Flights to Hartford" (was lowercase via `.capitalize()`).

### Agent C: Catalog data fixes (`clients/etraveli/catalog/accepted_proposal.json` + `src/catalog/`)

- **New `__sku__` diff type** in `cleaners.py::apply_proposal()`: renames a row's primary key with collision detection — when the target SKU already exists (e.g. NYC was already in the source data with real $452/24% discount), the source row is dropped and the target's data is preserved.
- **Three SKU remaps:** `Louisville` → `SDF` (+ `name="Louisville, KY"` + `from_price=200` placeholder); `NY` → `NYC` (collided with existing NYC row → source dropped, real data kept); `LON-Heathrow` → `LHR` (+ `name="London Heathrow"` + `from_price=350` placeholder).
- **IATA validator** (`src/catalog/validators.py::validate_iata_skus()`): warns on any non-IATA SKU at load time. Post-cleaning etraveli catalog has zero warnings.
- **Tests:** 20 new tests across `tests/test_iata_validator.py` and `tests/test_sku_remap.py`.

### Integration pass (orchestrator)

After all three agents completed, audit revealed three residual issues:

1. **`"Avoid {name} fare hikes"` pattern** in loss_aversion → rewrote to `"Avoid fare hikes today"` (name-independent, no harmful truncation possible).
2. **`"...in 60"` description truncations** → tightened the over-long description patterns (≥85 chars before name fill) to ≤70 chars, so even 20-char destination names stay under 90.
3. **Lowercase keyword fallback** ("Cheap flights to hartford") → added `_title_case_keyword()` helper that respects English stop-word convention.

Final scrub-list expansion: `"24h"`, `"60"`, `"policy"`, `"support"`, `"hour"`, `"side"`, `"online"`, `"seconds"`, naked-number tail tokens — all added to the incomplete-fragment drop list.
